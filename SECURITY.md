# Security policy

There is no supported production release of OTMP yet. The pre-release runtime
is experimental; reports against the current development line are welcome.

Report vulnerabilities privately using [GitHub private vulnerability reporting](https://github.com/daxis-io/OTMP/security/advisories/new).
Include the affected revision, reproduction steps, and impact. Do not include
credentials or publish an exploit in a public issue before coordinated disclosure.
