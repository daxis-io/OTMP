## Engine qualification findings

Published `turso_core = "=0.7.2"` with only `fs` fails to compile because its
incremental module references the optional `uuid` dependency. Enabling `uuid`
alongside `fs`, with defaults still disabled, resolves that published-feature gap.

Turso 0.7.2's shutdown checkpoint can swallow a non-Busy storage error. OTMP uses
an explicit checkpoint before close and a sticky adapter-failure flag checked
before freezing. The regression test first demonstrated the swallowed error,
then verified that the candidate cannot freeze through it. No engine fork or
alternate writer was introduced.

Eight adapter tests exercise exact ordinary-file output, initialization/header
capture, existing OTMP rows, deferred constraints, partial indexes, rollback,
failed commits/checkpoints, repeated writes, overflow/growth, truncation/regrowth,
and the shutdown guard. Structural tests cover multiple levels, midpoint and
serialized-size splits, EOF pruning, reused subtrees, and invalid child maxima.
Protocol/integration tests cover noncanonical and truncated objects, duplicate
pages, index offsets/overlap, hashes and conflicting references, missing extended
pages, both codecs, valid streaming zstd frames, and decompression overruns.
